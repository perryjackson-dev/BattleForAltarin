# Battle for Altarin

Browser strategy game foundation. Gameplay is not implemented yet.

## Requirements

Node.js 24 or later is recommended.

## Commands

```sh
npm install
npm run dev
npm run typecheck
npm test
npm run test:e2e
npm run build
```

## Stack

TypeScript, React, Vite, PixiJS, Tailwind CSS, Zustand, Dexie, Zod, Radix UI primitives, Lucide React, Vitest, and Playwright.
